# Скин «Minimalism» — Design Spec для реализации

Проект «Погода» · погода-про.ру + Telegram mini-app · 01.10.2026
Статус: визуальная концепция утверждена владельцем, документ — единственный источник правды для терминала. Терминал не додумывает дизайн: всё, чего нет здесь, берётся из Атласа скелета v3 без изменений.

Все размеры ниже — в логических px при ширине экрана 390 (CSS px). Замеры Атласа сделаны на канве 1320×2868 — коэффициент пересчёта ×3.385.

---

## 1. Принципы и утверждённые решения

1. Скин меняет только визуальный слой. Состав экранов (Э-1…Э-7), слоты и порядок в компонентах (К-01…К-20), шкала типографики (Т-1…Т-6), 20 слотов погодных иконок — по Атласу v3 без изменений.
2. Пара тем обязательна: светлая + тёмная для каждого экрана, компонента, иконки.
3. Характер скина: тёплая бумага + бронза, редакционная типографика, округлые виджеты (радиус 20px), тонкие линейные иконки. Никаких линий-рулов, рамок и декоративных элементов вокруг hero.
4. Точность и считывание данных важнее декора: запрещены любые графические «улучшения» строк данных (градиентные полосы диапазонов и т.п.). Строки дней — строго по К-07.

Утверждённые решения владельца (отклонения от первой концепции):
- **Д-Р1.** На Э-1 нет блока «текущая локация»: геолокация ненадёжна (VPN), главная — чистый hero + быстрые действия + избранное.
- **Д-Р2.** На Э-1 под hero — строка быстрого доступа из трёх кнопок: «Поиск», «Добавить», «Скин». Логика открытия: поиск → строка поиска; добавить → модалка Э-7; скин → экран К-20 (когда появится).
- **Д-Р3.** Шнур лампы не заходит на системный статус-бар (К-01): лампа висит ниже него, шнур начинается от нижней кромки статус-бара.
- **Д-Р4.** Э-2/Э-3 (точка) — структура строго исходная: навигация, заголовок+звезда, «Погода сейчас», 5 дней (К-07) с раскрытием часов (К-08) по тапу на день.
- **Д-Р5.** Э-6 «О проекте»: слово «Погода» без строки версии; единый блок манифеста (текст — константа, общая для всех скинов); кнопка доната.
- **Д-Р6 (отклонение от Атласа).** Кнопка «Поддержать проект (СБП)» красится в акцент скина (бронза), а не в брендовую бирюзу СБП. Атлас: «СБП — бирюза, узнаваемость не ломать» (К-17). Решение владельца от 01.10.2026: бирюза в Minimalism неуместна, кнопка живёт по правилам скина. Риск узнаваемости принят владельцем. Если решение будет пересмотрено — меняется только роль цвета кнопки (см. таблицу ролей, строка СБП).

## 4. heroControl — слово-кнопка и лампа (И-30)

### 4.1. Композиция hero (К-02) на Э-1

- Высота hero: 190px (после статус-бара 44px).
- Слово «Погода» — по центру, Playfair 52px/500, цвет «текст основной», оптически сдвинуто на 16px влево от геометрического центра (компенсация лампы справа).
- Под словом, по той же оси: «О ПРОЕКТЕ ›» (Т-3-подобная строка, 10px, разрядка 2.6px).
- Лампа — справа, 24px от правого края; колба висит на исходной высоте (контейнер лампы поднят на 28px над верхом hero). Шнур **укорочен**: начинается ниже нижней кромки статус-бара (Д-Р3) — в мастере SVG шнур идёт от y=28 до y=72 (длина 44), а не от верхней кромки.

### 4.2. Слово «Погода» = кнопка «О проекте»

- Тап по слову или строке «О ПРОЕКТЕ ›» → экран Э-6.
- Hit area: общая область слово + подпись, минимум 44px по высоте (фактически ~120×90px).
- Состояния: default; pressed — opacity слова 0.6, 120мс. Ховеров нет (touch).

### 4.3. Лампа = переключатель темы (И-30)

Метафора светила сохранена: лампа — источник света. Светлая тема = лампа «днём» (спокойный белый свет), тёмная = лампа горит тёплым янтарём. Тап = смена темы. Hit area 64×64px вокруг колбы.

SVG-структура (мастер, viewBox `0 0 120 240`, фон прозрачный):

```
<svg viewBox="0 0 120 240" fill="none">
  <defs><radialGradient id="glow" cx="50%" cy="52%" r="50%">…stops…</radialGradient></defs>
  <circle cx="60" cy="128" r="86" fill="url(#glow)"/>          <!-- halo -->
  <line x1="60" y1="28" x2="60" y2="72" …/>                    <!-- шнур, укорочен (Д-Р3) -->
  <path d="M50 72 h20 l3 18 h-26 z"/>                          <!-- патрон -->
  <path d="M60 90 C34 90 24 110 24 130 C24 153 40 166 60 166
           C80 166 96 153 96 130 C96 110 86 90 60 90 Z"/>      <!-- колба -->
  <path d="M44 138 L52 124 L60 138 L68 124 L76 138"/>          <!-- нить -->
</svg>
```

Параметры состояний:

| Элемент | Светлая | Тёмная |
|---|---|---|
| Шнур (stroke 2.4, round) | #A89E8D | #57503F |
| Патрон (fill) | #8A6B3A | #8A6B3A |
| Колба fill / stroke 1.6 | #FFFDF8 / #D9CFBE | #201D18 / #463F33 |
| Нить (zigzag, round) | #B9AD97, w=2.2 | #FFB75E, w=3.6 |
| Свечение (stops) | 0: #FFFDF6 α1 · .5: #FBEED4 α.45 · 1: α0 | 0: #FFBE66 α.8 · .42: #DE8F35 α.32 · 1: α0 |

Рендер-размер на экране: 104×208px (шнур 74px + колба ~76px + halo overflow:visible). Лампа — универсальный heroControl: в будущих скинах меняются только параметры состояний, структура SVG и слот в hero сохраняются.

## 5. Компоненты (визуальный слой поверх К-01…К-20)

Общее: радиус карточек и виджетов **20px**; радиус кнопок-пилюль **полный (height/2)**; разделители 1px цвета «разделитель»; обводок нет; тени по §2.

- **К-01** Шапка Telegram/статус-бар — не рисуем. Наш слой начинается ниже (лампа — тоже, Д-Р3).
- **К-02** Hero — см. §4.
- **Quick row (новый элемент Э-1, по Д-Р2):** три кнопки в одну строку, flex 1/3, высота 44px, радиус 22px, фон «вставка», иконка 15px акцент + подпись 12px/700 основной текст: «Поиск» (лупа), «Добавить» (плюс), «Скин» (полукруг-палитра). Hit area = вся кнопка.
- **К-04** Карточка точки: название (Т-1), высота (акцент, 12.5px/700), регион (Т-5), звезда И-15 справа сверху (13px, роль «звезда»), справа температура 19px/700 + иконка состояния 30px. Сетка 2 колонки, зазор 12px.
- **К-03** Полоса навигации: «‹ Все точки» слева (акцент), справа — «поделиться» и И-13 глобус (акцент, 17px). **Иконка «поделиться» — бумажный самолётик** (как «отправить» в Telegram; решение владельца от 01.10.2026, заменяет базовый арт «три точки с линиями»). Мастер 24×24, stroke 1.8, round: направляющая `M21.5 3.5 L10.8 14.2`, контур `M21.5 3.5 L14.5 21.5 L10.8 14.2 L2.5 10.5 Z`. Название точки ниже: Playfair 30px + звезда 16px; координаты строкой Т-5.
- **К-10** Кнопки карт: две пилюли 38px, фон карточки, бордер 1px разделитель, текст 12.5px/600.
- **К-05/К-06** «Сейчас»: карточка, лейбл Т-3 «ПОГОДА СЕЙЧАС · ОБНОВЛЕНО …»; строка: иконка 52px + температура Т-2 + состояние/«ощущается» Т-5; ниже разделитель и три метрики в ряд: ВЕТЕР / ОСАДКИ / ОБЛАЧНОСТЬ (лейбл 9px разрядка 1.2, значение 14.5px/700).
- **К-07** Строка дня — структура исходная: слева день (13px/700) + «макс°/мин°» (тёплая/холодная роль) + осадки мм (роль «осадки», 10.5px); центр — 4 иконки дня 24px; справа ветер м/с (11.5px/700) + облачность % (10.5px вторичный). Разделитель 1px между строками. Тап = раскрытие К-08.
- **К-08** Почасовая лента: 7 ячеек (час 9.5px вторичный, иконка 22px, t° 12px/700, мм 9px вторичный); ячейка «сейчас» — плашка фона «вставка», радиус 10px (рамка акцента из Атласа заменена плашкой — читается лучше на тёплом фоне).
- **К-09** Волны (Э-3): те же правила строк, что К-07.
- **К-11…К-14, К-16, К-18, К-19** — по общим правилам: карточки 20px, поля ввода фон «вставка» радиус 14px, CTA — Т-6 на акценте, плашка ошибки — роль «ошибка».
- **К-15/Э-5** Настройки: пункты строками с иконками И (служебный цвет 17px), СБП по Д-Р6.
- **К-17/Э-6** См. Д-Р5/Д-Р6: слово «Погода» Playfair 42px по центру → карточка манифеста (текст-константа, 12.5px/1.55) → кнопка доната 48px радиус 24.
- **К-20** Экран «Сменить стиль» — не существует, слот зарезервирован; кнопка «Скин» в quick row до появления К-20 ведёт на Э-5.

## 6. Погодные иконки — 20 слотов (таблица П)

Формат по Атласу: инлайн-SVG, мастер viewBox `0 0 24 24`, прозрачный фон, монохромные части красятся токенами `--i-sun, --i-moon, --i-cloud, --i-fog, --i-rain, --i-drz, --i-snow, --i-bolt, --i-wind`. Один мастер на всё, размер задаёт CSS: «Сейчас» 52–54px, дни 24px, часы 20–22px, карточка точки 30px, мелкие 13px.

Стиль скина: линейный контур, stroke 1.5 (в мастере 24×24), linecap/linejoin round, без заливок (кроме точек статуса). Ночные варианты — у 4 пар (sun/moon, sunCloud/moonCloud, rain/moonRain, snow/moonSnow): луна + явление, явление читается первым. Fallback неизвестных кодов — `cloud`.

Слоты: sun/moon (0,1) · sunCloud/moonCloud (2) · cloud (fallback) · overcast (3) · fog (45,48) · drizzle (51–57) · rain/moonRain (61,63) · rainShowers (65,80–82) · rainSnow (66,67) · snow/moonSnow (71–75) · blizzard (85,86) · hail (77) · thunder (95) · thunderHail (96,99) · wind · wave.

Базовые примитивы (пересчитаны в 24×24 из утверждённого арта):
- Облако: `M6.8 17.2 a4.1 4.1 0 0 1 .4-8.2 a5.3 5.3 0 0 1 10.1 1.1 a3.8 3.8 0 0 1 .3 7.1 z`
- Солнце: круг r5.2 в (12,12) + 8 лучей длиной 2.6 с шагом 45°
- Луна: `M15 3 a9 9 0 1 0 6 15.8 a7.5 7.5 0 0 1-6-15.8 z`
- Капли (rain): 3 штриха под облаком, наклон −8°, длина 2.6
- Снежинка: 3 перекрестия 60°, штрих 1.0
- Молния: `M12.8 16.5 l-2 3.3 h1.8 l-1.2 3`

## 7. Состояния, хит-эрии, адаптивность

- Минимальная хит-эрия любого контрола — 44×44px (лампа 64×64, слово-кнопка ~120×90, quick-кнопки 44 высота).
- Pressed-состояния: карточки и строки — opacity 0.7 или плашка «вставка», 120мс; кнопки на акценте — darken 8%.
- Переключение темы — мгновенная подмена токенов (CSS custom properties), без анимации перехода цвета дольше 200мс; лампа меняет состояние одновременно с темой.
- Сайт повторяет мини-апп 1:1 (Атлас Д-6): та же сетка, токены и компоненты; адаптив — max-width контента 430px по центру.

## 8. Что не входит в этот пакет

Э-8 «Сменить стиль» (появится после первого скина), состояния загрузки/ошибки сети (Д-2/Д-3), страница оплаты СБП (Д-4). Когда появятся — дополняем спеку по тем же токенам.
