# ЧАСТЬ 2. Спека скина «Тёма 299» (источник правды)

## 1. Принципы и утверждённые решения

1. Скин меняет только визуальный слой. Состав экранов (Э-1…Э-7), слоты и порядок в компонентах (К-01…К-20), шкала типографики (Т-1…Т-6), 20 слотов погодных иконок — по Атласу v3 без изменений.
2. Пара тем обязательна: светлая (солнечный день у моря) + тёмная (неоновый гараж, бёрнаут).
3. Характер скина: мультяшная сочность, «наливные» красочные иконки, плавные растянутые градиенты, скруглённая гарнитура. Никакой «топорности»: жёстких стыков цвета, угловатых шрифтов, плоских однотонных элементов.
4. Тексты — нейтральные (белый/серый/чёрный спектр), цвет несут только: температура (шкала), полоски, рамки кнопок, акцентные иконки. Надписи «Избранное» нет — виджеты идут сразу.
5. Точность и считывание данных важнее декора. Минимализм не должен перевешивать точность прогноза.

Утверждённые решения владельца (отклонения и особые договорённости):

- **Д-Р1 (отклонение от Атласа).** Температура красится не двумя статичными токенами, а непрерывной шкалой: +50° = бордовый, −50° = тёмно-синий, к нулю плавно бледнеют (красный → коралловый, синий → светло-голубой), 0° = светло-голубой. Цвета «лёгкие, не выцветают, легко читаемые». Формула и якоря — §5.
- **Д-Р2 (отклонение от Атласа).** Кнопка «Поддержать проект» — не бирюза СБП и не акцент: чистая белая заливка + голубая неоновая рамка со свечением, одинаково в обеих темах. Текст кнопки нейтральный тёмный. Голубой заливки внутри быть не должно («грязь»).
- **Д-Р3 (адаптация И-30).** Переключатель темы — тап по мотоциклисту с мотоциклом в арте шапки (центральная зона). Метафора светила сохранена: светлая тема = день/солнце, тёмная = ночь/неон. Отдельного виджета-переключателя в скине нет.
- **Д-Р4.** Ссылка на Instagram блогера живёт только в ночном арте: неоновая вывеска «@tema.polyana» (собака красная, текст синий), тап → https://www.instagram.com/tema.polyana?stkn=MW5uNTRkOTk1cW1vdQ== (внешняя ссылка, открывать в новом контексте). На лицевой странице иных упоминаний нет.
- **Д-Р5.** «О проекте» (Э-6) на лицевой странице скрыт в Easter eggs: ночная тема — тап по красному неоновому кружку с горящей «i» (дорисован в арте, в дыму между полосками); дневная — тап по круглому знаку «299» в руке мотоциклиста. Кто найдёт — кайфанёт.

| Зона | Светлая | Тёмная |
|---|---|---|
| t > 0 | #E2704B (коралл, +0⁺) → #7A0E2B (бордо, +50) | #F2BCA8 → #FF5A6E |
| t = 0 | #6FB9E8 (светло-голубой) | #CFE9F8 |
| t < 0 | #5BA8E0 (голубой, −0⁻) → #16338C (тёмно-синий, −50) | #CFE9F8 → #6FA8F5 |

Принцип владельца: к нулю цвет бледнеет, но НЕ выцветает — концы шкалы у нуля остаются читаемыми на карточке. Тёмная тема — осветлённые варианты той же шкалы.

Эталонная реализация (портировать 1:1):

```python
def lerp(c1, c2, k):
    a = [int(c1[i:i+2], 16) for i in (1, 3, 5)]
    b = [int(c2[i:i+2], 16) for i in (1, 3, 5)]
    return "#" + "".join(f"{round(a[i]+(b[i]-a[i])*k):02x}" for i in range(3))

def temp_color(t, dark=False):
    if t > 0:
        k = min(t / 50.0, 1.0)
        c = lerp("#E2704B", "#7A0E2B", k)
        if dark: c = lerp("#F2BCA8", "#FF5A6E", k)
    elif t < 0:
        k = min(-t / 50.0, 1.0)
        c = lerp("#5BA8E0", "#16338C", k)
        if dark: c = lerp("#CFE9F8", "#6FA8F5", k)
    else:
        c = "#6FB9E8" if not dark else "#CFE9F8"
    return c
```

Формат вывода: «+27°», «−12°», «0°» (минус — типографский −).
