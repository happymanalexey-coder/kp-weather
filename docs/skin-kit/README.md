# Skin-kit «Минимализм»: эталонные файлы base

Состав пакета (всё — точные копии из кода проекта, актуально на 26.09.2026, v3.5):

```
skin-kit/
  skin.js                  ← эталон токенов base: все 51 значение для dark и light
  badge.svg                ← бейдж «От разработчиков» 24×24 (эталон формата)
  icons/
    weather/               ← 19 погодных слотов (.svg, развёрнутые строки из app.js)
    ui/                    ← 8 интерфейсных слотов + wave
```

## 1. skin.js

Файл — полная копия `skins/base/skin.js`. Структура: `tokens.dark` и `tokens.light`, по 51 ключу.
Новый скин = тот же файл с другим `id`/`name`/`author` и своими значениями.
Не заданные ключи наследуются от base — для «Минимализма» можно переопределить только то, что отличается.

## 2. Иконки: как расставлены заливки (важно!)

Извлечено из движка 1:1. Механика по группам:

**Погодные (weather/):** заливки ЖЁСТКИЕ — hex-цвета + встроенные градиенты `url(#wg-*)` в `<defs>` каждой иконки.
Они одинаковы в обеих темах (полноцветный набор в духе Meteocons) и НЕ зависят от `var(--i-*)`.
Исключение: `wave.svg` и `wind.svg` красятся через CSS-класс `wnd` → `stroke: var(--i-wind)` — темо-зависимы.

**UI (ui/):** `gear, globe, pin, palette, check` — `currentColor` (наследуют цвет текста вокруг → автоматически работают в обеих темах). `telegram` — класс `tg-ico`, цвет задаёт CSS. `badge` — жёсткий градиент (голубая звезда с жёлтым бликом).

**Рекомендация для «Минимализма»:** чтобы иконки сами адаптировались к теме, используйте
`stroke/fill="currentColor"` (унаследуют цвет текста) или токены `var(--i-sun)`, `var(--i-cloud)` и т.д. —
движок примет любой валидный SVG; монохром на `currentColor` — самый надёжный вариант.
Токены `--i-*` задавайте в обеих темах (в base они есть, можно переопределить).

**Как скин подменяет иконку:** в `skin.js` → `icons: { <слот>: "<svg … целиком …>" }`.
Любой незаданный слот подставится из base. SVG — одной строкой, `viewBox="0 0 24 24"`, без `<?xml?>`.

**Размеры на экране (задаёт CSS, сам SVG без width/height):**
«Сейчас» 54px · дни 24px · часы 20px · детали дня 30px · мелкие 13px · UI 18px.

**Слоты погоды ↔ WMO-коды:** см. таблицу в гайде (п.6): https://pogoda-pro.ru/docs/skin-guide-for-designer.md

## 3. Что НЕ является SVG (не ищите в реестре)

Кнопки «✕» (закрыть), «←» (назад), шеврон «▾» и кнопка «i» (О проекте) — текстовые символы/буква в CSS-оформлении.
Скином они не подменяются; если «Минимализму» нужны свои начертания — скажите разработчику, он вынесет в слоты.
Переключатель темы (солнце/луна) — часть hero-SVG, цвета через `--hero-sun`/`--hero-moon`.

## 4. badge.svg

Эталон: `viewBox 0 0 24 24`, фон прозрачный. Скин кладёт свой символ в `skins/<id>/badge.svg` —
показывается на карточках «От разработчиков», в библиотеке и на экране точки (размер ~14–16 px).

## 5. Сдача

Папка `skins/minimalism/` (`skin.js` + `badge.svg`) + данные для реестра: name, author, 5 hero-цветов тёмной темы (sky0, sky1, mt1, mt2, mt3) и 4 цвета палитры для превью-карточки. Чек-лист приёмки — в гайде, п.9.
