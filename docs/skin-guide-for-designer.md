# Ответы дизайнеру: как устроен пакет скина «поставил — работает»

Проект: pogoda-pro.ru + Telegram mini-app, одна кодовая база, две темы (light/dark).
Актуально на 26.09.2026, версия кэша v3.5. Все цифры — из кода, не из памяти.

---

## 1. Ассеты: формат и размеры

**Всё векторное, инлайн-SVG, `viewBox="0 0 24 24"`** (кроме hero). PNG в интерфейсе нет вообще (PNG только иконка приложения `icons/icon-192.png`, она скином не меняется). Размер задаётся CSS на месте использования, поэтому @2x/@3x НЕ нужны, фон — всегда прозрачный.

| Слот | Размер на экране | CSS-класс |
|---|---|---|
| Крупная иконка «Сейчас» | 54×54 px | `.now-icon .wic` |
| Строки дней (5-дневка) | 24×24 px | `.day-icon .wic` |
| Почасовой прогноз | 20×20 px | `.h-icon .wic` |
| Погодный блок в донате/деталях | 30×30 px | `.dp-ico .wic` |
| Мелкие в строке дня (облачность, ветер) | 13×13 px | `.d-right .wic` |
| UI-иконки (шестерёнка, глобус, пин, палитра, чек, телеграм) | 18 px (кнопки настроек) и наследуемые | `.sic` |
| Статусные точки (зелёная/жёлтая/красная) | 9×9 px, CSS-круг | `.vdot` |
| Бейдж «От разработчиков» | 24×24 viewBox, показывается 14–16 px | `skins/<id>/badge.svg` |
| Hero главной | инлайн-SVG `viewBox 400×160`, высота блока 200 px | `.hero-mountains` |
| Переключатель темы (солнце/луна) | часть hero-SVG, см. п.7 | — |

**Как скин поставляет иконки:** не файлами, а строками SVG внутри `skin.js` в объекте `icons: { <слот>: "<svg …>" }`. Отдельный файл — только `badge.svg`.

## 2. Пакет скина: структура

Скин = папка из 2 файлов + 1 запись в реестре. Точный состав на примере base:

```
skins/
  skins.json          ← реестр всех скинов
  base/
    skin.js           ← токены (цвета обеих тем) + опционально icons{}
    badge.svg         ← бейдж «От разработчиков» 24×24
```

`skins/skins.json` — массив записей:

```json
{ "id": "base", "name": "Базовый", "author": "От разработчиков",
  "file": "skins/base/skin.js", "badge": "skins/base/badge.svg",
  "preview": { "sky0": "#101c30", "sky1": "#0b1220",
               "mt1": "#16243c", "mt2": "#0f1930", "mt3": "#0a1120",
               "palette": ["#16223a", "#63d6d0", "#e07856", "#e8eef7"] } }
```

Новый скин = `skins/minimalism/skin.js` + `skins/minimalism/badge.svg` + одна строка в массиве. Больше нигде код не трогаем — движок сам подхватит.

`skin.js` — это JS-файл формата:
```js
window.KP_SKINS = window.KP_SKINS || {};
window.KP_SKINS.minimalism = {
  id: "minimalism", name: "Минимализм", author: "<имя студии>",
  tokens: { dark: { "--bg": "#000", … }, light: { "--bg": "#fff", … } },
  icons: { sun: "<svg …>", … }   // необязательно; любой слот можно не задавать — подставится base
};
```
Эталон для копирования — `skins/base/skin.js` (в нём все ключи 1:1).

## 3. Цвета: полный список CSS-переменных

Движок читает эти ключи из `tokens.dark` и `tokens.light` (не заданные = наследуются от base). Все 51 ключ на тему:

**Поверхности и текст:**
`--bg` (фон приложения и зоны системной строки), `--bg2`, `--card`, `--card2`, `--line`, `--text`, `--text2`, `--muted`

**Акцент и семантика:**
`--accent`, `--on-accent`, `--on-accent2`, `--terracotta`, `--green`, `--yellow`, `--red`, `--blue`, `--tmax` (тёплая t°), `--tmin` (холодная t°), `--prc` (осадки)

**Фоны-подложки и тени:**
`--head` (липкие шапки, rgba с прозрачностью), `--overlay` (модалки), `--accent-soft`, `--accent-glow`, `--green-bg`, `--yellow-bg`, `--red-bg`, `--red-soft`, `--shadow`, `--shadow2`

**Хиро-сцена (11 шт):**
`--hero-sk0`, `--hero-sk1` (небо, градиент), `--hero-mt1`, `--hero-mt2`, `--hero-mt3` (три плана гор), `--hero-snow`, `--hero-moon`, `--hero-sun`, `--hero-sub` (слоган), `--hero-shadow`, `--hero-globe-shadow`

**Кнопка «i» на hero:**
`--hi-border`, `--hi-color`, `--hi-bg`, `--hi-glow`, `--info-border`, `--info-color`

**Погодные иконки (монохром-слоты):**
`--i-sun`, `--i-moon`, `--i-cloud`, `--i-fog`, `--i-rain`, `--i-drz`, `--i-snow`, `--i-bolt`, `--i-wind`

Сопоставление с 16 ролями атласа: базовые роли = `--bg / --card / --line / --text / --muted / --accent / --green / --yellow / --red / --blue` + хиро-группа + семантика t°/осадков. Если атласу не хватает ролей — добивайте по группам выше, я сверю.

## 4. Шрифты

Сейчас — системный стек: `-apple-system, "SF Pro Text", "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif`.

Токены типографики: `--fs-base: 16px`, `--fs-small: 13px`, `--fs-title: 24px`, `--lh-base: 1.45`, `--fw-bold: 800`, `--fw-semi: 650`.

**Свой шрифт можно.** Специальной ручки нет, но `skin.js` — исполняемый JS: в начало файла добавьте инжект (даю готовый сниппет по запросу). Требования: woff2, кириллица обязательна, `font-display: swap`, рекомендую ≤150 КБ суммарно (жёсткого лимита нет, но mini-app грузится по мобильной сети). Начертания, которые реально используются: 400, 650, 800 — остальные не пакуйте.

## 5. Радиусы, отступы, тени

| Токен | Значение | Где |
|---|---|---|
| `--r-hero` | 24 px | нижнее скругление hero |
| `--r-lg` | 18 px | крупные карточки («Сейчас») |
| `--r-md` | 16 px | стандартные карточки |
| `--r-sm` | 14 px | строки, часы |
| `--r-xs` | 12 px | мелкие элементы |
| `--r-btn` | 10 px | кнопки |
| `--r-pill` | 999 px | табы, пилюли |
| `--pad` | 16 px | боковые отступы сетки |
| `--gap` | 10 px | зазор сетки карточек |
| `--app-max` | 520 px | ширина колонки |

**Тени:** скин меняет только ЦВЕТ (`--shadow`, `--shadow2`) — геометрия теней (смещения, блюр) захардкожена в CSS, скином не настраивается. Если «Минимализму» нужно убрать тени — задать `--shadow: rgba(0,0,0,0)`.

**Что разрешено менять:** технически — любой из токенов (движок применит всё, что положите в `tokens`). Практически: первый скин рекомендую ограничить цветами и иконками; радиусы/отступы влияют на выверенную сетку (приёмка — `scrollWidth === innerWidth` на 320/375/390/430). Меняете геометрию — гоняем регрессию вместе.

## 6. Коды погодных условий

Все источники (ECMWF, ICON, GFS, MET Norway) приходят через Open-Meteo, который нормализует всё в единый **WMO weathercode** — один код на все источники, разбираться по моделям не нужно. Marine API — отдельный слот `wave` (волна, не WMO).

Полный маппинг код → слот (ночные варианты там, где указано):

| WMO-коды | Значение | Слот |
|---|---|---|
| 0, 1 | ясно | `sun` / ночью `moon` |
| 2 | переменная облачность | `sunCloud` / `moonCloud` |
| 3 | пасмурно | `overcast` |
| 45, 48 | туман, изморозь | `fog` |
| 51, 53, 55, 56, 57 | морось (в т.ч. ледяная) | `drizzle` |
| 61, 63 | дождь | `rain` / `moonRain` |
| 65, 80, 81, 82 | сильный дождь, ливень | `rainShowers` / `moonRain` |
| 66, 67 | ледяной дождь | `rainSnow` |
| 71, 73, 75 | снег | `snow` / `moonSnow` |
| 77 | снежная крупа | `hail` |
| 85, 86 | снегопад, метель | `blizzard` |
| 95 | гроза | `thunder` |
| 96, 99 | гроза с градом | `thunderHail` |
| fallback (любой неизвестный) | — | `cloud` |

**Итого 20 погодных слотов:** `sun, moon, sunCloud, moonCloud, cloud, overcast, fog, drizzle, rain, rainShowers, rainSnow, snow, blizzard, hail, thunder, thunderHail, moonRain, moonSnow, wind, wave` (`wind` — для строки ветра, `wave` — для волн). Ни один WMO-код без иконки не останется: неизвестный код падает в `cloud`. Привязывайте ваши П-01…П-18 к этим слотам — если слотов больше, чем условий атласа, лишние можно не рисовать (подставится base).

## 7. Переключатель темы

**Не отдельный ассет — часть инлайн-SVG hero** (index.html, внутри viewBox 400×160):
- солнце: круг r=10 в точке (302, 64) + 8 лучей;
- луна: path-полумесяц там же, повёрнута на 30°;
- зона клика: прозрачный круг r=26.

Скину доступны цвета `--hero-sun` и `--hero-moon`. Сама геометрия сейчас фиксирована — **если дизайнеру нужна своя форма солнца/луны, это реализуемо: скажите, и я вынесу её в слот скина** (как погодные иконки).

## 8. Экран «Сменить стиль» (К-20)

**Превью-картинка НЕ нужна** — миниатюра собирается кодом из цветов в `skins.json → preview`:
- `sky0, sky1` — небо мини-хиро (тёмная тема);
- `mt1, mt2, mt3` — три плана гор;
- `palette` — ровно 4 цвета для кружков палитры.

От скина для этого экрана нужно: `id` (латиница, kebab-case), `name` (до ~20 символов), `author`, 5 hero-цветов, 4 цвета палитры. Регистрация = одна строка в массиве `skins.json` (см. п.2). Кнопка «Применить» переключает мгновенно, выбор хранится в localStorage (`kp_skin`), у сайта и mini-app — свои хранилища, синхронизации нет (осознанно).

## 9. Тестовый прогон

1. Кладёте `skins/<id>/` (skin.js + badge.svg) в проект, добавляете строку в `skins.json`.
2. Открываете приложение → Настройки → «Сменить стиль» → «Применить» — смотрите обе темы (переключатель солнце/луна в hero).
3. Локальный стенд без релиза: `python3 -m http.server 8901` из папки `web/` → `http://localhost:8901`.
4. Могу сделать удобнее: **URL-параметр `?skin=<id>`** для мгновенной проверки без захода в настройки (скажите — добавлю за 10 минут) и/или выкладывать кандидата на тестовый URL до релиза.

Чек-лист приёмки скина: обе темы, экраны главная/точка/библиотека/настройки/донат, `scrollWidth === innerWidth` на 320/375/390/430, бейдж на карточках и в библиотеке, экран «Сменить стиль» (своё превью).

## 10. Что вы не спросили

- **Состояния загрузки**: skeleton-плашки (пульс 1.4 c, фиксирован) и спиннер — цвета берут из `--card`/`--line`/`--accent`, скином настраиваются автоматически; сама анимация не токенизирована.
- **Экран ошибки** («Нет сети», кнопка «Повторить»): цвета из общих токенов, отдельных слотов нет.
- **Шапка Telegram mini-app**: красится в `--bg` автоматически (`applyTgColors`) — следите, чтобы `--bg` был именно тем цветом, который должен сливаться с шапкой TG.
- **Анимации и звуки**: скином не настраиваются (звуков в приложении нет).
- **Иконка приложения** (home-screen, manifest): скином НЕ меняется — это `icons/icon-192.png`, один на проект.
- **Геометрия hero** (силуэты гор): фиксирована в SVG-path; вынесу в слот по запросу (как и солнце/луну, п.7).
- **Донат-блок**: цвета из токенов; эмодзи 🙏 в кнопке — не иконка реестра (если «Минимализм» хочет без эмодзи — это правка текста, не скина).
- **Ограничение длины**: названия точек и полей ужимаются ellipsis — в макетах не закладывайте длинные строки без запаса.

### Контракт сдачи скина (коротко)
1. Папка `skins/<id>/`: `skin.js` (tokens dark+light, опц. icons) + `badge.svg` 24×24.
2. Строка в `skins/skins.json` (+ 5 hero-цветов и 4 цвета палитры для превью).
3. Прогон по чек-листу п.9.
Дальше — моя регрессия и релиз. Вопросы и сниппеты (шрифт, ?skin=) — по запросу.
