# Погода в горах — Красная Поляна · Абхазия

Telegram Mini App (работает и как обычный сайт): сводка погоды по 32 горным
и прибрежным точкам Красной Поляны и Абхазии. Клик по точке → погода сейчас,
завтра и на 5 дней, вердикт «стоит ли идти», микро-анализ на завтра,
ссылки на Windy и Mountain-Forecast.

## Быстрый старт

```bash
cd krasnaya-polyana-weather
python3 server.py            # или: npm run dev
# открыть http://localhost:7100/
```

Python 3.10+, сторонних зависимостей нет — только стандартная библиотека.
Порт можно переопределить: `python3 server.py --port 8080`.

## Показать другу (публичная ссылка)

```bash
./share.sh
```

Скрипт поднимет сервер и бесплатный туннель Pinggy — в терминале появится
публичный HTTPS-адрес вида `https://xxxx.free.pinggy.net`. Его можно
отправить кому угодно. Ограничение бесплатного туннеля — 60 минут;
для новой сессии просто перезапустите скрипт (адрес будет новый).

## Подключение к Telegram-боту (@broKimibot)

Приложение готово к работе как Mini App: SDK Telegram подключается
асинхронно, страница адаптирована под мобильный экран.

1. Поднимите публичный HTTPS-адрес (см. `./share.sh`; для постоянной работы
   лучше задеплоить на хостинг — см. ниже).
2. Откройте @BotFather → `/mybots` → выберите @broKimibot →
   **Bot Settings → Menu Button → Configure/Edit menu button URL** →
   вставьте HTTPS-адрес → задайте текст кнопки, например «Погода в горах».
3. Откройте @broKimibot в Telegram — внизу появится кнопка меню с приложением.

Токен бота хранится в `.env` (`TELEGRAM_BOT_TOKEN`, файл в `.gitignore`,
права 600). Для Mini App токен не нужен — он понадобится для уведомлений.

## Источники данных

| Источник | Что даёт | Ключ |
|---|---|---|
| Open-Meteo (best_match) | текущая погода, почасовой и дневной прогноз | не нужен |
| Open-Meteo (ECMWF IFS, GFS, ICON-EU) | независимые модели для разброса | не нужен |
| MET Norway (Locationforecast) | третий независимый источник | не нужен |

Все три — без ключей и бесплатно. Ответы агрегируются: среднее по источникам
+ разброс (min–max) температур. Если источник не ответил — сводка собирается
по оставшимся, а сбойный источник честно показывается в строке «не ответили».

В `.env` заложены переменные `VISUAL_CROSSING_KEY`, `WEATHERAPI_KEY`,
`OPENWEATHERMAP_KEY` — они зарезервированы под следующий шаг (платные
источники по ТЗ), в коде пока не используются.

## Кэш

`cache/{id}.json`, TTL 30 минут (`CACHE_TTL_MIN` в `.env`). Повторные
открытия точки в течение TTL не ходят в сеть.

## Вердикты

- 🔴 **Не стоит**: гроза, осадки ≥ 8 мм/сутки или ветер ≥ 15 м/с.
- 🟡 **Осторожно**: осадки ≥ 2 мм, ветер ≥ 8 м/с или облачность ≥ 90 %.
- 🟢 **Отлично**: всё остальное.

Микро-анализ на завтра: окна осадков по часам, лучшее окно для выхода,
ветер, туман, гроза + совет «Взять: …».

## Структура

```
server.py          — бэкенд (stdlib): статика + /api/points + /api/weather, кэш, агрегация
web/index.html     — оболочка (hero, экраны)
web/styles.css     — тёмная тема
web/app.js         — фронт: hash-роутинг, рендер сводки
data/points.json   — 32 точки: id, имя, координаты, высота, регион
docs/              — отчёт по координатам и источникам (шаг 1)
share.sh           — сервер + публичный туннель одной командой
tools/cloudflared  — запасной туннель (Cloudflare; в некоторых сетях режется)
```

## Как обновить точки

Правите `data/points.json` (id, name, lat, lon, ele, region) — сервер
подхватывает файл на каждый запрос списка, перезапуск не нужен. Кэш погоды
для изменённой точки удалите: `rm cache/<id>.json`.

## Осознанные отклонения от ТЗ

- **React/Vite → vanilla JS без сборки.** Надёжнее для MVP: ноль зависимостей,
  работает где угодно. Миграция на React возможна позже без изменения API.
- **Уведомления отложены** (по решению владельца) — в интерфейсе стоит
  плейсхолдер. План: бот шлёт сводку за сутки до похода (нужен polling
  getUpdates или webhook + chat_id пользователя).
- **Платные источники (Visual Crossing, WeatherAPI, OWM)** не подключены —
  три бесключевых источника уже дают разброс моделей; ключевые API —
  следующий шаг.

## Постоянный деплой (когда туннеля 60 минут мало)

Сервис — один файл `server.py` без зависимостей: поднимается на любом
хостинге с Python 3 (Render, Railway, VPS). После деплоя постоянный
HTTPS-адрес вставляется в Menu Button бота тем же способом, что выше.
